## Секреты для сборки

Значения хранятся только в GitHub → репозиторий → Settings → Secrets and variables → Actions. Ни в коде, ни в этом репозитории их нет и быть не должно.

| Имя секрета | Что это | Статус |
|---|---|---|
| `MS_TOKEN` | токен API МоегоСклада | нужно добавить |
| `YC_SA_KEY` | ключ сервисного аккаунта Яндекс Облака (тот же, что у SpaceKit Logistic) | нужно добавить |
| `YC_FOLDER_ID` | ID каталога в Яндекс Облаке (тот же, что у Logistic) | нужно добавить |

Telegram не используется: всё общение и уведомления внутри приложения.

## Что сделано в демо

- Вход заказчика по телефону (код из звонка) + имя и компания при первом входе.
- Заявка: объект (14 полей проекта МоегоСклада + дом, «Дополнительная информация»), товары — ссылка на корзину Петровича или список текстом, система расшифровывает в позиции.
- Менеджер: доска по статусам, сопоставление позиций с товарами МоегоСклада, цены, отправка на подтверждение, подтверждение по телефону.
- Статусы: Новая → В обработке → На подтверждении → Передана на сборку (+ Отменена).
- Чат в каждой заявке, колокольчик уведомлений, включение push.
- Компании: история заказов, суммы, объекты, контакты. У заказчика — «Повторить заявку».

## Что в демо ненастоящее

Звонок с кодом, МойСклад, push и расшифровка корзины Петровича только изображаются. Каталог товаров и коды — тестовые. Данные хранятся в браузере.
